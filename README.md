# 微信 · Windows Island

消息岛官方微信插件，提供新消息通知、会话免打扰和头像补全。

请使用支持独立微信插件的消息岛版本。在 **插件管理 → 发现插件** 中找到作者为 `winiofficial` 的微信插件，安装后阅读条款并启用。微信退出时显示未运行，重新打开后自动恢复连接；连接失败可在插件详情重试。停用后停止监听，卸载保留设置。

默认插件源已开放，微信插件的收录状态以该列表为准。微信连接能力需要默认源验证，手动导入 ZIP 不会取得该能力。插件不上传聊天内容。

发布包见 [Releases](https://github.com/WinIOfficial/wini_plugin_wechat/releases)，公开发布与默认源收录分别生效。安装与管理说明见[使用文档](https://wini-docs.abszero.cc/guide/plugins)。
